WHY CANTON

This product needs privacy the protocol enforces

PRIVACY BY PROTOCOL

Each firm, its own node

A node receives only the contracts its firm is party to. No operator has to be trusted to hide margins.

ONE TRUTH

No shared database

Every tier sees the same acceptance at the same moment, with ledger timestamps that hold up later.

MULTI-PARTY

Rules, not email

Both firms sign each link. Acceptance, obligation and payment are enforced by the contract.

A public chain would expose every amount. A private database run by one firm would mean trusting that firm with everyone’s margins. Canton’s sub-transaction privacy is the reason this works.
